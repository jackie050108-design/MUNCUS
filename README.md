# muncus.org
Static website for MUNCUS — Model United Nations Club Union of Shanghai (上海模拟联合国社团联盟).

- Edit content in `build.py`, then run `python3 build.py` to regenerate the HTML pages.
- Styles: `assets/css/style.css`. Logos: `assets/img/`.
- `CNAME` points GitHub Pages at **muncus.org**. Enable Pages (Settings → Pages → deploy from branch), then add DNS records at your registrar: A records for `@` → 185.199.108.153 / .109.153 / .110.153 / .111.153, and a CNAME for `www` → `<user>.github.io`.
- `[Bracketed]` text marks placeholders awaiting real content.
